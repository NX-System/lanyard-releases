# Lanyard

A native macOS menu bar app that manages your Claude Code profiles: accounts, sessions, rules, IDE hand-off and usage, from one place. By [Nexus Systems](https://nxsys.app).

**Download:** the latest build is on the [Releases](https://github.com/NX-System/lanyard-releases/releases/latest) page and at [lanyard.nxsys.app](https://lanyard.nxsys.app). Open the `.dmg` and drag Lanyard to Applications.

**Requirements:** macOS 14 or later, Apple silicon or Intel, Claude Code installed.

**Support:** [lanyard-support](https://github.com/NX-System/lanyard-support) for bugs, requests and questions, or support@nxsysdev.com.

This repository holds the builds, the release notes and the update feed. Lanyard is distributed as a binary under the [end user license](https://lanyard.nxsys.app/eula); its source code is not published.
