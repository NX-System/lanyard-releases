# Lanyard downloads

This repository holds the release builds of **Lanyard**, the macOS menu bar app for Claude Code profiles by [Nexus Systems](https://nxsys.app). Each release carries the signed `.dmg` and its SHA-256.

- Latest build and release notes: [Releases](https://github.com/NX-System/lanyard-releases/releases)
- Website and documentation: [lanyard.nxsys.app](https://lanyard.nxsys.app)
- Support: [lanyard-support](https://github.com/NX-System/lanyard-support) or support@nxsysdev.com

The "Source code" archives GitHub attaches to every release contain this README only. Lanyard's source is not published; the app is distributed as a binary under its [end user license](https://lanyard.nxsys.app/eula.html).
