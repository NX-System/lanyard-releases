Lanyard

Privacy Policy

Lanyard for macOS. Effective 2026-11-17. Published by Nexus Systems.

Short version: Lanyard runs on your Mac and reads Claude Code's own files there. It has no account, no analytics and no telemetry. The only data that leaves your Mac is a support report you review and send yourself, and a request to check for updates.

What Lanyard reads on your Mac

Lanyard works with the files that Claude Code already keeps in your home folder: profile configuration folders, session transcripts, rules files, and the Claude Code credential stored in the macOS Keychain. It reads them to show your profiles, sessions, rules and usage. It writes to them only when you take an action, such as switching a profile, renaming a session, editing a rule or moving a session to the recycle bin.

Lanyard uses the Claude Code credential on your Mac to fetch your plan usage from Anthropic's service and to refresh that credential when it expires. The credential never leaves the Keychain except for those requests, which go directly from your Mac to Anthropic.

What leaves your Mac

  • Update check. Lanyard asks this site's release feed on GitHub whether a newer build exists. The request carries the app version and the standard information any web request carries, such as your IP address. GitHub's privacy policy applies to that request.
  • Usage requests. When Live usage is on, Lanyard calls Anthropic's usage endpoint with your Claude Code credential. Anthropic's privacy policy applies.
  • Support reports. When you press Send in Settings → Support, Lanyard files the report you reviewed. Before showing it to you, Lanyard removes home folder paths, project folder names, email addresses and anything that looks like a token or key. The report goes to our public support repository on GitHub, and, if you add a reply address, to our support mailbox. Anything you type into the report yourself is sent as typed. Public issues are visible to anyone.

Nothing else is sent. Lanyard contains no analytics, crash reporting or advertising code.

What we keep

We keep support reports and the email conversations around them for as long as needed to resolve them and to recognise repeat problems. We do not sell or share them. Public issues on GitHub stay public unless you ask us to remove one; GitHub's own retention applies there.

Your choices

  • Turn off the update check or Live usage in Settings.
  • Review every support report before it is sent, and leave diagnostics out with one switch.
  • Ask us to delete a report or an email thread by writing to support@nxsysdev.com.

Children

Lanyard is a developer tool and is not directed at children under 16.

Changes

If this policy changes, the new version is published here with a new effective date. Material changes are noted in the release notes of the build that introduces them.
