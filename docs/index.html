Lanyard

Your Claude Code profiles, from the menu bar.

Lanyard keeps every Claude Code account, its sessions, rules and usage in one native macOS app. Switch profiles in a click, resume a chat in your IDE, and see where your plan stands.

Download for macOS
macOS 14 or later. Free during the beta. Release notes

What it does

Profiles

One entry per Claude Code account or config folder. Switch the active profile from the popover; terminals and IDEs follow.

Sessions

Every chat across every profile, searchable, renameable, with a recycle bin. Resume one in the terminal or straight in VS Code.

Live usage

Plan and usage at a glance, refreshed without any login dialogs.

Rules

Per-profile and per-project CLAUDE.md rules edited from a friendly UI, with a view of what is in effect.

IDE hand-off

A bundled VS Code extension picks up the session you choose and opens it in the right window.

Support built in

Report a problem from Settings; Lanyard shows exactly what it will send, with paths and tokens removed.

FAQ

Does Lanyard send my data anywhere?
No. It reads Claude Code's own files on your Mac. The only network calls are the update check against this site and, when you press Send, the support report you reviewed.
Is it open source?
No. Lanyard is distributed as a signed binary under the end user license. Bug reports and requests are public on GitHub.
Which Macs?
Apple silicon and Intel, macOS 14 or later, with Claude Code installed.
How do updates work?
Lanyard checks this site for new builds and tells you when one is ready. Updates are signed; nothing installs without you saying so.
